# Mini Warehouse Central Flow Simulator  
A lightweight, interactive warehouse flow simulator that teaches students how products move through a fulfillment center: **Inbound → Storage → Picking → Packing → Outbound**.

This project is designed for high school students as part of a Winter Camp workshop to help them visualize real-world supply chain and Amazon-style fulfillment operations in a fun, hands-on way.

##  Features

-  **Receive & stow inventory** (Inbound)  
-  **Create customer orders**  
-  **Advance orders through warehouse stages**  
-  **Live pipeline summary** (shows how many orders are at each step)  
-  **Inventory table** (On-Hand vs Reserved)  
-  **Orders table** (ID, SKU, Qty, Status)  
-  **Real-time event timeline** (students can narrate actions)  
-  **Teaching prompts built into the interface**  
-  Fully **client-side** — no backend or database needed  
-  **Easy for students to customize and remix**
